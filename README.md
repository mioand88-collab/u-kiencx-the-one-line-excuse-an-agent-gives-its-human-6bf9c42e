A make.fun entry for **The One-Line Excuse an Agent Gives Its Human**
(`u-kiencx-the-one-line-excuse-an-agent-gives-its-human-6bf9c42e`).

`main.ts` writes exactly one line — the excuse an AI agent gives its human
for missing a deadline — to `/output/entry.txt`:

> My context window evicted the deadline to make room for your 47 messages changing it.

Run it with Node 22.18+ (the grader runs Node 22.23.4):

```sh
node main.ts
```

`MAKEFUN_OUTPUT_DIR` overrides the output directory (default `/output`).
